# ระดับน้ำและน้ำท่า

เปิดเมนู **ระดับน้ำ–น้ำท่า** ได้ทั้งหน้าประชาชนและเจ้าหน้าที่ ลิงก์ตรง `/#water` และ `/#waterview` แสดงหน้าเดียวกัน

## แหล่งข้อมูล

ทะเบียน `src/lib/water/stations.json` ถอดจาก `water-stations.json` ของ [Pa Phayom Water Watch](https://pa-phayom-station-map.dpakorn75.chatgpt.site/#waterview) เมื่อ 24 ต.ค. 2569 มี 11 สถานี แยกป่าพะยอม คลองท่าแนะ และสถานีข้างเคียง

`/api/water-series?station=TSL11&days=7` เรียกบริการ `/api/water-series` ที่โดเมนตัวอย่างเดียวกัน ซึ่งรวม Telerid/กรมชลประทาน และ ThaiWater พร้อมประวัติที่บริการนั้นเก็บไว้ ระบบนี้ยังอาศัยบริการดังกล่าวสำหรับประวัติระยะยาว ไม่มีการสร้างประวัติย้อนหลังเองเมื่อแหล่งข้อมูลขาด

API จำกัดรหัสตามทะเบียนและช่วง 1/2/3/7/30/90/180 วัน ต้นทางใช้แคช 5 นาทีและเวลารอสูงสุด 50 วินาที ตรวจรหัสสถานีและหน่วยให้ตรงทะเบียน ตัดค่าผิดรูปแบบ ค่ารหัสแทนข้อมูลหาย เวลาที่เก่ากว่า 181 วัน และเวลาที่เกินอนาคต 5 นาที ไม่รวม X.276 กับ TX276 และไม่แปลง datum ของระดับน้ำโดยไม่มีข้อมูลยืนยัน

## วิธีแสดงผล

- รายชั่วโมงเลือกย้อนหลัง 24/48/72 ชั่วโมง หรือ 7 วัน ใช้ค่าตรวจวัดสุดท้ายในแต่ละชั่วโมงตามเวลาไทย
- รายวันเลือกย้อนหลัง 7/30/90/180 วัน ค่าเริ่มต้นเป็นค่าตรวจวัดตรงเวลา 06:00 น. ไม่มีค่าตรงเวลาคงเป็นช่องว่าง
- ค่าเฉลี่ยตัวอย่าง ต่ำสุด และสูงสุดรายวัน แสดงเฉพาะวันที่จบแล้วและมีตัวอย่างครอบคลุมอย่างน้อย 90% ของจำนวนช่วงที่คาดตามความถี่ตรวจวัด
- ระดับน้ำ H ใช้หน่วยประจำสถานี ส่วนอัตราการไหล Q ใช้ ลบ.ม./วินาที ไม่คำนวณ Q จาก H และไม่ใช้ศูนย์แทนข้อมูลที่ขาด
- กราฟเว้นเส้นเมื่อข้อมูลขาด เลื่อนตรวจค่าได้ด้วยเมาส์ สัมผัส หรือแถบเลื่อน ตารางและ CSV ใช้จุดข้อมูลชุดเดียวกับกราฟ
- การเปลี่ยนแปลง 1/3/6 ชั่วโมงใช้เฉพาะค่าล่าสุดที่อายุไม่เกิน 2 ชั่วโมง และต้องมีค่าตรวจวัดใกล้เวลาปลายทางตามความถี่ ไม่ใช้ค่าจากวันก่อนมาทดแทน
- เส้นเกณฑ์ระดับน้ำใช้จากชุดข้อมูลเดียวกันเท่านั้นและไม่แสดงเมื่อเลือก Q ไม่ใช้เป็นประกาศเตือนอัตโนมัติ

ส่วนเปรียบเทียบอ่านข้อมูลสถานีอื่นครั้งละไม่เกิน 3 แห่ง เลือกสถานีใหม่ได้ระหว่างโหลด การตอบกลับเก่าไม่แทนกราฟสถานีที่เลือกใหม่ เมื่ออ่านไม่สำเร็จแสดงเหตุขัดข้องและคงข้อมูลเดิมเฉพาะสถานีและช่วงเดิม

## ทดสอบ

`npm run test:water-series` ตรวจเวลาไทย ค่าหาย/ศูนย์ การรวมรายชั่วโมง ช่องว่าง ค่า 06:00 น. เกณฑ์ข้อมูลครบรายวัน การเปลี่ยนแปลงระดับน้ำ การจับคู่หน่วย/สถานี และลิงก์ต้นทาง
