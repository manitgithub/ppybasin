# ชั้นประมาณฝนเชิงพื้นที่

เปิดได้ในแผงชั้นข้อมูลบนแผนที่ประชาชนและแผนที่หน้าแรกเจ้าหน้าที่ เลือก Thin-plate spline หรือ IDW ระยะทางกำลังสอง ปรับความทึบ และกดพื้นที่เพื่อดูค่าประมาณได้ ใช้ขอบเขตลุ่มน้ำป่าพะยอม/คลองท่าแนะตามชั้นขอบเขตที่เปิดอยู่

ใช้ทะเบียน 24 แห่งจาก [เว็บอ้างอิง](https://pa-phayom-station-map.dpakorn75.chatgpt.site/#rainview) และค่าฝนสะสม 24 ชั่วโมงจาก ThaiWater พัทลุง นครศรีธรรมราช และตรัง ไม่ใช้ฝน 12 ชั่วโมงหรือยอดตั้งแต่ 07:00 น. แทนฝน 24 ชั่วโมง

## การคัดข้อมูล

- ค่าฝน 0–1,000 มม. มีพิกัดและเวลาตรวจวัด ใช้ศูนย์ได้เมื่อเป็นค่าตรวจวัดจริง
- อายุไม่เกิน 2 ชั่วโมง เวลาในอนาคตไม่เกิน 5 นาทีเพื่อรองรับความคลาดเคลื่อนนาฬิกา
- เลือกกลุ่มเวลาที่มีสถานีมากที่สุดโดยปลายช่วงสะสมต่างกันไม่เกิน 60 นาที ถ้าเท่ากันใช้กลุ่มใหม่กว่า
- เก็บค่าล่าสุดต่อรหัสและใช้พิกัดไม่ซ้ำกัน ต้องมีอย่างน้อย 3 จุดที่ไม่อยู่ในแนวเส้นตรง

## การคำนวณและแสดงผล

คำนวณระยะทางในหน่วยกิโลเมตรด้วยการฉายพิกัดท้องถิ่น IDW ใช้ `1/d²` และคืนค่าตรวจวัดเมื่อประเมินตรงสถานี ส่วน TPS ใช้ kernel `r² log(r)` ร่วมกับพหุนามดีกรี 1 และเงื่อนไข `Pᵀa = 0` ตาม [สมการ RBFInterpolator ของ SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.RBFInterpolator.html) แปลงค่าฝนด้วย `log1p` สเกลพิกัด 50 กม. และ smoothing 0.01 ก่อนแปลงกลับด้วย `expm1` จำกัดผล TPS ระหว่างศูนย์กับค่าฝนสูงสุดในชุดข้อมูลตามแนวทางเว็บอ้างอิง

กริดแสดงผลกว้าง 180 ช่อง สุ่มตำแหน่งในแนวตั้งตาม Web Mercator เพื่อให้ตรงกับ ImageOverlay พื้นที่นอก polygon และช่องว่างภายในโปร่งใส ใช้สีเฉพาะใน convex hull ของสถานีและระยะไม่เกิน 15 กม. จากสถานีที่ใกล้ที่สุด พื้นที่ในลุ่มน้ำที่ไม่ผ่านเงื่อนไขนี้ใช้ลายแรเงา ไม่แทนด้วยฝนศูนย์ ร้อยละพื้นที่รองรับเป็นสัดส่วนช่องกริดภายในขอบเขตที่คำนวณได้ ไม่ใช่ตัวชี้วัดความแม่นยำ

พื้นสีเป็นค่าประมาณระหว่างสถานี แยกจากหมุดค่าตรวจวัดและภาพเรดาร์ คำนวณใหม่เมื่อสถานี วิธี ช่วงเวลาตรวจข้อมูล หรือขอบเขตเปลี่ยน การปรับความทึบไม่คำนวณกริดซ้ำ ไม่มีการใช้ผลนี้สร้างประกาศเตือนอัตโนมัติ

## ตรวจสอบ

`npm run test:rain-interpolation` ตรวจคำตอบเชิงวิเคราะห์ของ IDW/TPS ค่าฝนศูนย์ การคัดเวลา สถานีซ้ำ จุดเรียงเส้นตรง การตัดขอบเขตและช่องว่าง รวมถึงพื้นที่ที่ไม่มีข้อมูลรองรับ
