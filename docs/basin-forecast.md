# เมนูคาดการณ์

เข้าผ่าน `#forecast` ในหน้าประชาชน และเมนูคาดการณ์ของเจ้าหน้าที่ (`basin-forecast`, สิทธิ์ `dashboard:view`) เมนูคาดการณ์และแจ้งเตือนเดิมของผู้มีสิทธิ์จัดการประกาศยังอยู่

## แหล่งข้อมูล

- ฝนรายวัน: สสน. / ThaiWater WRF-ROMS (ThaiGeo), API `https://api-v3.thaiwater.net/api/v1/thaiwater30/provinces/wrfrom_rainforcase7d?province_code=93` และหน้า `https://phatthalung.thaiwater.net/forecast/rainfall` เป็นค่าระดับจังหวัด ไม่ตีความเป็นฝนรายสถานีหรือค่าเฉลี่ยลุ่มน้ำ รอบสะสมตามเว็บอ้างอิง 07:00–07:00 น. ไทย
- ฝนรายชั่วโมง: ผล TMD NWP domain 2 ที่เว็บอ้างอิงบันทึกผ่าน `https://pa-phayom-station-map.dpakorn75.chatgpt.site/api/tmd/series` ไม่ส่งหรือร้องขอ TMD token และไม่เรียกให้เว็บอ้างอิงสร้างชุดพยากรณ์ใหม่
- ขอบเขต: `/data/tmd-basin.geojson` ของเว็บอ้างอิง คัดลอกโดยคงพิกัด/วงแหวน/metadata เป็น `public/boundaries/pa-phayom-forecast.geojson` SHA-256 ของชุดต้นฉบับที่ระบุใน metadata: `dcd87248d83be02fbadf56fe786d2886c3f4d948fb93b13f92e7a333c5a05ca0` ตรวจว่าตรงกับข้อมูลรายภาพก่อนแสดง
- ภาพต้นฉบับรายวันแสดงทันทีตามวันที่เลือกแทนกราฟแท่ง ผ่าน `/api/rain-forecast-image?date=...` ของเว็บอ้างอิง ระบุความไม่ตรงกันของเวลาไฟล์ภาพกับวันพยากรณ์ และให้ตรวจช่วงเวลาที่หัวภาพ

`/api/basin-forecast` อ่านสองชุดขนานกัน มี timeout 25 วินาทีและ cache 10 นาที คืนผลบางส่วนได้เมื่ออีกชุดไม่พร้อม ไม่เปลี่ยน `/api/forecast` ซึ่งใช้กับหน้าปฏิบัติการเดิม

## วิธีแสดงผล

เลือกวันเพื่ออ่านภาพ ค่า และช่วงสะสม เน้นคำแปลผลตาม rainfall_text ของ สสน. โดยตรง ไม่สร้างเกณฑ์ฝนหนักจากตัวเลขขึ้นใหม่ แถบสรุปวันที่ฝนหนักเลือกจากวันที่ต้นทางจัดเป็นฝนหนัก/หนักมากในชุดที่ยังใช้งานได้ ตาราง/CSV คงช่องว่าง ไม่แทนด้วยศูนย์ วันหมดช่วงใช้งานไม่แสดงเป็นพยากรณ์อนาคต ไม่สร้างเวลาออกรอบจากเวลารับข้อมูล

แผนที่ TMD ใช้ bilinear ภายในเซลล์ที่มีข้อมูลครบทุกมุม ไม่ประมาณนอกกริด ตัดผิวสีด้วยขอบเขตและวงแหวนภายใน พื้นที่ไม่มีข้อมูลแสดงแรเงา ค่าเฉลี่ยถ่วงด้วยพื้นที่ตัวแทนที่ต้นทางคำนวณแบบ Thiessen/Voronoi แสดงค่าเฉลี่ยทั้งลุ่มน้ำเมื่อพื้นที่ครบและทุกจุดที่แทนพื้นที่มีค่าฝนเท่านั้น ไม่คำนวณค่าเฉลี่ยจากภาพ raster

ทุกภาพคงหน่วยฝนของช่วงรายชั่วโมง ไม่รวมหลายภาพเป็นฝนสะสม 24 ชั่วโมงเมื่อเวลาออกรอบ/ช่วงสะสมยังไม่ยืนยัน ชุดที่เวลาผ่านแล้วมีข้อความชัดเจน ไม่ใช้เปลี่ยนสถานะเตือนภัยอัตโนมัติ ไม่มีผล H/Q น้ำไหลเข้า หรือพื้นที่น้ำท่วมจำลองที่สร้างขึ้นทดแทนโมดูลที่ยังไม่พร้อม

ส่วน “ภาพนิ่งเทียบหลายเวลา · สเกลสีเดียวกัน” พับไว้เริ่มต้น เมื่อเปิดแสดงทุกเวลาที่มีในชุด รวมเวลาที่ข้อมูลขาด ใช้ตัววาดผิวสีเดียวกับแผนที่หลัก ขอบเขต มุมมอง การประมาณ bilinear และช่วงสีเหมือนกัน ไม่ปรับช่วงสีตามค่าสูงสุดของแต่ละภาพ สร้างภาพเฉพาะใกล้บริเวณที่กำลังดูเพื่อลดภาระเบราว์เซอร์ เลือกภาพเพื่อกลับไปดูช่วงเวลานั้นบนแผนที่ได้ ดาวน์โหลด PNG พร้อมปี/วัน/เวลา หน่วย ค่าเฉลี่ย ค่าสูงสุด ความครอบคลุม คำอธิบายสี และชื่อแหล่งข้อมูล ไม่สร้างภาพแทรกหรือแทนค่าขาดด้วยศูนย์

ทดสอบด้วย `npm run test:basin-forecast` รวมขอบเขตจังหวัด รอบเวลาไทย ค่าหาย/ศูนย์ วันหมดอายุ metadata ภาพ ถ่วงพื้นที่ ช่วงขาด และขอบเขตการประมาณ bilinear
